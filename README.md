# Personal Agent

Personal Agent is a personal productivity app for planning work, tracking routines, and keeping university tasks in one place. It is designed for everyday use with a simple, responsive interface.

## Features

- Today view for a quick overview of tasks, schedule, habits, and daily priorities
- Task management with due dates, subjects, subtasks, progress tracking, and completion history
- Plan view for creating and editing scheduled events and recurring schedules
- Uni-board for classes, lectures, tutorials, labs, assessments, milestones, agendas, and links
- Habit tracking with daily and weekly views
- Learning paths with topics, progress, study time, and learning resources
- Project boards for organizing projects and related ideas
- Focus timer for working on a selected task and recording focused time
- Personal assistant for questions about tasks, schedules, habits, and projects
- Guest mode with local storage and optional account sync through Supabase
- Light and dark themes with a responsive layout

## Built with

- React
- Vite
- Supabase
- Tailwind CSS
