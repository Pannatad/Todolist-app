# Sound Assets

This directory should contain the following sound files:

- `plant.mp3`: Played when a new task is added (seed planted).
- `water.mp3`: Played when a task is completed/harvested.
- `ambient.mp3`: (Optional) Background music.

Currently, these files are placeholders. The application should handle missing files gracefully, but for the best experience, please add valid MP3 files with these names.
